# AI-Assisted Ad Operations for a Utah First-Time-Buyer Real Estate Practice: Tools, Compliance, Programs, and Benchmarks

*Research date: August 12, 2026. Serving Davis, Weber, and Salt Lake counties, focused on first-time buyers/sellers.*

## TL;DR
- The endpoint you named — **`mcp.facebook.com/ads` — IS real and IS Meta's official Ads MCP server**, launched in open beta on April 29, 2026 as part of "Meta Ads AI Connectors." But the large majority of servers marketing themselves as "Meta Ads MCP" (Pipeboard, GoMarble, AdKit, Composio, etc.) are unofficial third-party servers. Verify you connected through Meta's own OAuth flow with **no API key/token** — if a tool asked for a key, you are on a third-party server that holds spending authority over your account.

Named ads-specific packages fail the star bar: adkit/ads-skills (5 stars), hyperfx-ai/marketing-skills (67 stars), whyashthakker/agent-skills-marketing (12 stars); irinabuht12-oss/marketing-skills clears stars (447) but its install count is unverifiable. ## Key Findings

### 1. The "official Meta Ads MCP" claim — VERIFIED TRUE, with a critical caveat
Meta did publish an official MCP server at `https://mcp.facebook.com/ads`. This is confirmed by Meta's own Meta for Business announcement, "Introducing Meta Ads AI Connectors" (posted April 29, 2026), and corroborated by trade press (PPC Land, "Meta opens its ad system to Claude and ChatGPT," May 1, 2026). The umbrella product is "Meta Ads AI Connectors," comprising (a) the hosted MCP server at that endpoint and (b) an Ads CLI installed via npm. Per Meta's post, an on-page update dated **July 16, 2026** added two capabilities: connecting any AI app via your own developer app, and "ads MCP server rules" letting a business-portfolio admin govern what AI agents can do (budget changes, catalog updates).

Independent technical coverage (AdMove AI, 2026) reports the connectors "expose 29 tools across five capability areas," authenticate via "Meta Business OAuth rather than the traditional Developer App and App Review process," and that "every campaign, ad set, and ad created through the connectors lands in PAUSED status." Both interfaces cut setup from days to minutes.

**The caveat that matters for you:** the majority of "Meta Ads MCP" search results are third-party/community servers — Pipeboard (a badged Meta Business Partner, but still independent), GoMarble, AdKit, Adzviser, Composio, ArmaVita, and others. Many are legitimate and use Meta's public APIs, but they are **not** Meta's first-party server. The distinguishing test: **the official server authenticates via Meta Business OAuth and requires no API key or long-lived access token.** If any tool asked you for a key/token, you connected to a third-party server, not Meta's endpoint.

### 2. Credible Claude skills for Meta/Google Ads — the honest picture
- **Install counts are only publicly and verifiably exposed on skills.sh** (Vercel Labs' registry), which shows per-skill install numbers and a telemetry-ranked leaderboard. Per skills.sh docs, "the skills leaderboard ranks skills based on anonymous telemetry data collected from the skills CLI." GitHub stars are verifiable on each repo page. There is no universal, audited cross-ecosystem install metric, and researchers note skills.sh rankings are gameable (Vercel's own response is a Snyk scanning partnership, not human review).
- **anthropics/skills (the official Anthropic repo, ~167k stars) contains NO advertising/Meta Ads/Google Ads skill.** Its ~17 example skills are document/creative/technical (PDF/docx/pptx/xlsx, canvas-design, algorithmic-art, mcp-server, webapp-testing, brand-guidelines, internal-comms). Anyone citing an "official Anthropic ads skill" is mistaken; the closest is brand-guidelines, which is not paid media.
- **vercel-labs/agent-skills exists** (~29.9k stars, directly observed) but is Vercel's engineering collection (Next.js/React performance, web-design guidelines, docs review) — **it contains no ads skills.** (Note: the sibling repo vercel-labs/skills is the CLI tool itself.)
- **No dedicated ads package clears both bars.** Directly observed GitHub stars (Aug 12, 2026): adkit/ads-skills = **5**; hyperfx-ai/marketing-skills = **67**; whyashthakker/agent-skills-marketing = **12**; irinabuht12-oss/marketing-skills (Ryze AI) = **447**. Only irinabuht clears 100+ stars, but its skills.sh install count could not be found, so 1,000+ installs is **unconfirmed**.
- **The only thing clearing both bars is a general marketing library:** coreyhaines31/marketingskills (**43.8k stars**; ad-related sub-skills like ad-creative ~95K installs, paid-ads ~55K, ads ~46K on skills.sh). It is not ads-dedicated and **not housing-aware.**
- **Terminology (routinely conflated in listings):** A *skill* is a SKILL.md instruction file that teaches the model a repeatable method — knowledge, no live data. An *MCP server* is a live pipe that reads/acts on your ad account — access, not method. A *plugin* is a marketplace-packaged bundle (often skills + config) installed via a `/plugin` marketplace command. You need an MCP connector for live account data; a skill alone only supplies the method.

### 3. No credible real-estate/lead-gen-specific ad skill exists
No real-estate-specific or lead-generation-specific advertising skill package surfaced that meets any reasonable credibility bar — **none found.** Available ads skills are generic (campaign structure, creative briefs, fatigue/diagnostics) and **none demonstrably handle Housing Special Ad Category constraints.** This is the single biggest risk for your use case: a generic ads skill will suggest age/ZIP/interest targeting that is prohibited for housing, and following it could get ads rejected or your account restricted. Compared to generic skills on maintenance/recency, the generic packages are more active (2025–2026 commits) but still non-compliant for housing by default.

### 4. Meta Housing Special Ad Category — current rules (HEC: Housing, Employment, Credit)
When "Housing" is declared, Meta removes/restricts:
- **Age** (all housing ads target 18+; no age ranges), **gender** (shown to all), **ZIP-code/precise geo** (no geofencing a neighborhood or ZIP), and most **detailed interest/behavior/demographic** options (income, net worth, "luxury home buyer," etc.).
- **Audience exclusions are disabled.**
- **Lookalike Audiences are replaced by "Special Ad Audiences."** Custom Audiences from your own first-party data (CRM lists, past clients, website/pixel visitors, video engagement) remain usable.
- **Minimum geographic radius is 15 miles** (around a pin; targeting a city is allowed at that minimum). Multiple 2026 practitioner sources and Meta's own documentation references confirm the 15-mile figure. One source (Denote, 2026) cited a "15km" figure — this appears to be an error/rounding; the consistently cited U.S. figure is **15 miles**. Radius, cities, counties, and DMAs are all still available so long as the 15-mile minimum is respected.
- **2026 enforcement is multimodal and automated:** Meta's classifiers analyze images (floor plans, exteriors, "For Sale" signs), copy, landing pages, and account history, and auto-apply the Housing category even if you didn't select it. Trying to evade is flagged as an "Evasion" violation, degrades account health, risks ad rejection/account restriction, and can create **Fair Housing Act** exposure.

**VRS / DOJ–HUD settlement history and status:** The Variance Reduction System stems from the June 2022 DOJ/HUD settlement in *United States v. Meta Platforms* (SDNY), which alleged Meta's housing-ad delivery violated the Fair Housing Act. Under the settlement, Meta ceased the "Special Ad Audience" lookalike tool for HEC ads, paid a $115,054 civil penalty, and built VRS to reduce delivery variance by sex and estimated race/ethnicity (measured via privacy-enhanced BISG), verified by third-party reviewer Guidehouse. **Court oversight ran through June 27, 2026.** VRS operates at the delivery-algorithm level (not something you configure) and continues to apply to housing ads; the settlement facts are 2022–2023 and are flagged as older-than-6-months context.

**Google Ads equivalent (for comparison):** Google's "Housing in personalized advertising" restriction (US/Canada) prohibits targeting or excluding by age, gender, marital status, parental status, and ZIP code, on top of longstanding bans on sensitive categories (race, religion, etc.). You **can** target by city, county, state, DMA/region, and a "privacy-safe radius." Customer Match/remarketing are restricted only if they use the prohibited signals. Full Canadian postal codes are restricted but the 3-character FSA is allowed. Non-compliant ads are blocked from serving in the US/CA; advertisers get 60 days to accept the policy or ads stop serving.

### 5. Utah first-time buyer programs (2026) — ad-angle material
**Utah Housing Corporation (UHC):** FirstHome, FHA/VA, Freddie Mac HFA Advantage, Score, and NoMI are active; **HomeAgain is temporarily suspended** (repeat buyers should use FHA/VA or HFA Advantage). Down payment assistance is up to **6% of the first mortgage, capped at $27,500**, in one of two structures (per SuperMoney's 2026 Utah DPA guide): a **traditional** second at 1 percentage point above your UHC first-mortgage rate (ceiling 8%), or a **deferred** second at 3.5% accrued interest with no monthly payment. FirstHome requires roughly a 660 credit score for conventional; homebuyer education is required. Purchase-price limits by county (2026, per mortgage-info.com, updated May 2026): **Salt Lake $562,000, Davis $555,000, Weber $495,000** (Utah County $542,000; Summit/Park City $650,000 high-cost). Income limits vary by county/household; in Salt Lake County a family of two is roughly $110,700 (aggregator figure — confirm current numbers on UHC's limits page).

**SB 240 First-Time Homebuyer Assistance Program:** Up to **$20,000, 0% interest, deferred (no monthly payment)**; **new construction only, never-occupied, purchase price ≤ $450,000**; buyer must be a Utah resident 12 months and not have owned in 3 years; program capped at roughly 2,400–2,500 buyers, first-come first-served through participating lenders. Repayment at sale/refinance is the lesser of $20,000 or 50% of home equity. **Still active in 2026**, and the Legislature this session added **another ~$10 million** (per KSL's session wrap-up). Program performance (data supplied by the Utah Senate to Building Salt Lake, as of **Jan 30, 2026**): UHC "has awarded these loans to 2,934 households around the state, with the average loan totaling $19,948," and over **$58.5 million** distributed; average home price ~$388,698 and average awardee household income ~$90,321. Senate President Adams stated the program would see **no eligibility/terms changes** and would keep the new-build requirement. A separate 2026 bill, **HB 541** (Rep. Verona Mauga), proposed extending assistance to existing homes (up to $10,000) — **introduced but not confirmed passed** as of research; treat as pending.

**County/city programs:**
- **Own in Ogden** (Ogden city limits, 0% deferred, repaid at sale/refi, first-time not required): **$10,000** general / **$15,000** state-certified K-12 teachers & Ogden City employees / **$20,000** sworn Ogden police & firefighters. Price cap ~$430,000 existing / ~$467,000 new (aggregator figures).
- **Weber County grant:** ~**$5,000**, secured as a lien, forgiven after 5 years (CDBG-funded); also federal HOME-funded deferred loans in the Ogden area.
- **Davis County Homeownership Assistance:** 1% loan up to **$50,000**, deferred, repaid at sale/refi, ≤80% AMI, not limited to first-time buyers; **2025 funds were exhausted, applications scheduled to reopen ~July 1, 2026** (funding status flagged — confirm before advertising).
- **Salt Lake City HOME:** ~$10,000; **CDCU** (Salt Lake City/County/Taylorsville) deferred forgivable loan; **NeighborWorks Salt Lake** ~$10,000 forgivable; **West Valley City** forgivable loans up to ~$14,999.
- **FHLB HELP:** ~$20,000 forgivable grant (5-year owner-occupancy), available across Weber County.

**Federal:** FHA (3.5% down, 580+ credit), VA (0% down, no PMI), USDA (rural, 100% financing). 2026 FHA single-family loan limit ~$524,225 in Salt Lake/Utah/Davis counties.

*Flag: most county/city dollar amounts above come from lender/aggregator sites, not primary county pages — reconfirm with the county or a participating lender before building creative around them.*

### 6. Meta Ads CPL/CPC benchmarks for residential real estate
**No Salt Lake City metro-specific public CPL benchmark exists.** All figures below are national or tier-based, and sources disagree substantially — present them as a band, not a point estimate:
- **LocaliQ / WordStream (2025 data, n≈726 US leads-objective campaigns, Apr 2024–Jun 2025):** real estate Facebook lead **CPL $16.61** (among the lowest of any industry), CTR 3.75%, conversion 9.53%; the all-industry leads-objective average was $27.66, up ~21% YoY, with the all-industry average CPC around $1.92. *(>6 months old — flagged as stale.)*
- **Adamigo (2026):** real estate **$51.90 average CPL**; Tier 1 metros (NYC/LA/Miami) $35–$65; **Tier 2 metros (Denver/Austin/Nashville) $20–$45**; Tier 3 $8–$20; Lead Form Ads $34.10 vs Video Ads $45.80. Projections for 2026 cited at $54.50–$57.00 — note "projection" language.
- **Superads (~$3B ad-spend dataset):** global CPL averaged around $41.53 with heavy seasonality; the real-estate series (Jul 2025–Jun 2026) averaged **~$29.50**, ranging from **$16.21 (Nov 2025) to $40.27 (Jan 2026)** — a ~46% trough-to-peak swing.
- **Practitioner ranges (2026):** buyer lead forms ~$35–$65; seller "What's Your Home Worth?" valuation offers ~$15–$35 (consistently the lowest-CPL offer); some low-competition markets as low as ~$2.44 (a floor, not a norm).

**The disagreement is the finding:** as admanage.ai notes, "the variance between tables (Real Estate at $16.61 in one study vs $51.90 in another) highlights how much methodology, dataset, and lead definition matter. Use both tables as bookends." Salt Lake City behaves like a **Tier 2 metro**, so a working planning band of roughly **$20–$45 per lead** is reasonable — but this is inference from national tier data, not a measured Salt Lake figure. **Special Ad Category constraints are widely reported to raise real estate CPMs/CPL** by forcing broad audiences, but **no clean, quantified "restricted vs. unrestricted" delta exists in public sources** — do not cite a specific inflation percentage.

## Details

### Security & permission implications of MCP servers with spending authority
- The **official Meta MCP inherits the permissions of whoever authenticates** via OAuth, with three scope tiers (read-only; read/write; read/write/financial), granted per user and per account. Campaigns created via the connectors land **PAUSED** by default — a deliberate guardrail.
- **Third-party servers that hold an access token** (rather than using Meta's OAuth) insert a broker between you and your ad-account spend. Reports circulated in early 2026 of Meta account restrictions tied to unsanctioned AI/scraping integrations; Meta has not confirmed specific tools, and most flagged accounts were using browser automation, not approved API integrations. The official server materially reduces this risk because Meta owns token issuance, refresh, and revocation.
- **Practical rule:** start read-only for ~2 weeks; validate that what the agent reads matches Ads Manager; never grant read/write/financial to a skill or server you cannot identify; require human review before any budget change >20% or before un-pausing a campaign; verify the connector URL is exactly `https://mcp.facebook.com/ads`.

## Recommendations
1. **Confirm what you actually connected (do this first).** In Claude → Settings → Connectors, verify the server URL is exactly `https://mcp.facebook.com/ads` and that setup used Meta OAuth with **no API key**. If it asked for a token/key, you're on a third-party server — disconnect and reconnect via the official endpoint. Keep the scope at read-only until you trust it.
2. **Do not rely on a generic ads skill for compliance.** Because no housing-aware skill exists, paste a written Housing-SAC checklist into any Claude project/skill: declare Housing category; no age/gender/ZIP; 15-mile minimum radius; first-party Custom Audiences + Special Ad Audiences only (no plain Lookalikes); neutral/inclusive copy (no "perfect for young families," etc.); human approval before un-pausing.
3. **If you want a curated skill,** the only both-bars option is the general **coreyhaines31/marketingskills** library (43.8k stars) — use its ad-creative and diagnostic skills for *method*, never for targeting decisions. Treat vendor "#1 / 30k-star / 281K-install" claims (e.g., Hyper's blog) as marketing; verify stars on the repo page yourself. adkit/ads-skills, hyperfx-ai, and whyashthakker all **fail** your 100-star bar today.
4. **Build ad angles around live programs, verified before launch:** SB 240 ($20K, new construction ≤$450K) for new-build buyers (Daybreak-type communities); Own in Ogden tiers ($10K/$15K/$20K) for Weber; Davis County $50K deferred (confirm the ~July 2026 reopening); UHC FirstHome + up-to-6%/$27,500 DPA stack. Because several programs cycle annually or exhaust funds, confirm current funding with a participating lender before running any campaign that names a dollar amount — an exhausted program in your ad is a false-advertising risk.
5. **Benchmark to a band, not a number.** Target ~$20–$45/lead for Salt Lake metro planning; expect seasonal Q4→Q1 cost pressure; run seller "home valuation" offers for lowest CPL and buyer lead forms for intent; use 3-field forms plus fast follow-up (speed-to-lead) to protect quality. Re-benchmark against your *own* account after ~50 conversions and treat that as your real number.

**Thresholds that change the plan:** if your CPL runs sustained above ~$65, fix creative/offer before touching targeting; if Meta auto-flags an ad you didn't mark as Housing, stop and re-declare the category (don't rebuild to evade); if a DPA program you advertise is exhausted, pull the creative immediately.
